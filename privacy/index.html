1. 앱의 용도

이 앱(kkultem-upload)은 운영자 본인의 유튜브 채널에 영상을 올리는 용도로만 쓰입니다.

2. 수집하는 개인정보

이 앱은 다른 사람의 개인정보를 수집·저장·공유하지 않습니다.

3. 구글 로그인 정보의 보관

구글 로그인 정보(인증 토큰)는 운영자 컴퓨터에만 저장되며, 외부 서버로 보내거나 다른 사람과 공유하지 않습니다.

6. 사용하는 데이터 / Data Used

이 앱이 사용하는 데이터는 본인 채널에 영상 업로드, 채널 확인(읽기)뿐입니다. 다른 사용자의 데이터는 사용하지 않습니다.

This app only uploads videos to the operator's own channel and reads channel information to verify it. It does not use any other user's data.

7. 삭제·철회 / Deletion and Revocation

운영자는 언제든 https://myaccount.google.com/permissions 에서 이 앱의 접근 권한을 철회할 수 있으며, 철회하면 저장된 토큰은 삭제됩니다. 토큰 삭제 요청은 mpdone1@gmail.com 으로 보낼 수 있습니다.

The operator can revoke this app's access at any time at https://myaccount.google.com/permissions; once revoked, the stored token is deleted. Token deletion requests can be sent to mpdone1@gmail.com.

8. 데이터 보관 / Data Storage

토큰은 운영자 컴퓨터에만 보관되며 서버로 전송하지 않습니다.

Tokens are stored only on the operator's computer and are never sent to any server.
